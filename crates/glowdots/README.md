# glowdots

A 1990s pinball dot matrix display (DMD) engine: round plasma dots with
afterglow, halo, and bloom; a deck of scenes with pinball transitions;
pixel fonts and drawing helpers. Any panel size. Runs in a window on
macOS, Windows, and Linux, in the browser, or on a Raspberry Pi panel.

See the [project README](https://github.com/ztaylor/glowdots) for
pictures, the showcase, and a guide to writing a scene.
