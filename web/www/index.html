glowdots

Source on GitHub

Tap the right half of the display for the next scene, the left half to go back. Once you tap it, the arrow keys work too.

A 1990s pinball dot matrix display, for anything you want to show. Write a scene in Rust, feed it JSON, and run it in a window, in a web page, or full screen on a Raspberry Pi.

Everything here is the real engine, compiled to WebAssembly: the round plasma dots, their glow and afterglow, the pinball transitions, and the example scenes. Change the controls and the display follows.

Run it on your computer

git clone https://github.com/ztaylor/glowdots
cd glowdots
cargo run --release

Then make it yours: a whole scene fits in 30 lines.
